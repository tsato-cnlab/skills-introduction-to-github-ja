# GitHub 入門

_1 時間以内で GitHub の使い方を始めましょう。_

## ようこそ

世界中の人々が、GitHub を使って最先端の技術を作っています。データを可視化する場合でも、新しいゲームを作る場合でも、GitHub には作業をより良く進めるためのコミュニティとツールがそろっています。GitHub Skills の「GitHub 入門」演習では、1 時間以内でコントリビューションを始めるために必要な内容をひと通り学べます。

- **対象者**: 新しい開発者、GitHub を初めて使う人、学生。
- **学べること**: リポジトリ、ブランチ、コミット、プルリクエストを紹介します。
- **作るもの**: [プロフィール README](https://docs.github.com/account-and-profile/setting-up-and-managing-your-github-profile/customizing-your-profile/managing-your-profile-readme) として使える短い Markdown ファイルを作成します。
- **前提条件**: ありません。この演習は、GitHub を使い始める初日にぴったりの入門教材です。
- **所要時間**: この演習は 1 時間以内で完了できます。

この演習では、次のことを行います。

1. ブランチを作成する
2. ファイルをコミットする
3. プルリクエストを開く
4. プルリクエストをマージする

### この演習の始め方

演習を自分のアカウントにコピーします。その後、お気に入りの Octocat である Mona が最初のレッスンを準備するまで **約 20 秒** 待ち、**ページを再読み込み** してください。

<summary>うまくいきませんか？</summary><br/>

演習をコピーするときは、次の設定をおすすめします。

- owner には、リポジトリを置く個人アカウントまたは Organization を選びます。
- プライベートリポジトリでは Actions の実行時間が消費されるため、パブリックリポジトリの作成をおすすめします。

20 秒待っても演習の準備ができない場合は、[Actions](../../actions) タブを確認してください。

- ジョブが実行中かどうかを確認します。単に少し時間がかかっているだけの場合があります。
- 失敗したジョブが表示されている場合は、issue を作成してください。バグを見つけてくれてありがとうございます！
